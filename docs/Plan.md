# 桑多涅桌面机器人项目计划

## 目标与首版范围

项目最终希望制作以《原神》桑多涅为角色蓝本、可交互的小型人形桌面机器人。首版目标是**可演示原型**，暂以**桌面小车形态**作为载体；首版无需移动，人形外观留待后续版本。

首版已确认的要求：

- 语音交互同时支持固定口令及其预设回应、开放式语音对话；开放式对话允许联网。
- 使用触摸屏；根据场景显示不同表情，并给出相应语音反馈。首版具体场景和反馈内容待定。
- 通过 Type-C 接口充电，充电时机器人必须能够继续运行；拔掉充电线后仍能依靠电池运行。电池类型待选，暂无续航目标。
- 体积尽量小，具体尺寸待结构与元件方案确定。单台成本争取控制在 1000 元人民币以内；如无法满足功能，可据实际方案调整。
- 首版无需移动，不安排底盘驱动和避障功能。

项目资料按外观与机构（`Model/`）、电路（`PCB/`）、软件（`Software/`）整理。当前三个目录均尚无实现内容，`docs/FunctionDef.md`、`docs/ParaDef.md` 和 `docs/ElecCompSel.md` 尚未填写。

## 阶段计划

### 1. 定义演示场景与验收标准

在 `docs/FunctionDef.md` 写明一段完整的首版演示流程，明确固定口令、开放式对话的演示要求，以及触摸屏场景、表情和语音反馈。在 `docs/ParaDef.md` 记录小型化目标、Type-C 充电与电池运行要求、单台成本目标和使用环境；尚未决定的参数保持待定。

**完成标志：** 每项首版功能都有可观察的验收方式，演示流程和必要参数已确认。

### 2. 验证关键功能并确定方案

分别验证固定口令识别与回应、联网开放式语音对话、触摸屏表情与语音反馈，以及 Type-C 边充边用和拔线后电池运行。核对这些模块的体积与物料成本，优先寻找能使单台成本不超过 1000 元的方案。根据验证结果画出模块连接关系，并在 `docs/ElecCompSel.md` 记录元件选择、价格、供电需求和替代方案。

**完成标志：** 关键功能有可运行的独立验证结果，主要元件和模块接口已确定。

### 3. 制作小车原型

- **结构：** 设计并制作尽量小、能安装电池、电路、屏幕和音频部件的桌面小车形态外壳；首版无需运动机构。
- **电路：** 完成 Type-C 充电、电池供电、控制、屏幕、触摸和音频相关电路的连接和检查。
- **软件：** 实现固定口令及预设回应、开放式语音对话，以及触摸屏场景、表情和语音反馈逻辑。

**完成标志：** 各模块能够独立运行，结构可完成装配，接口资料可供联调使用。

### 4. 装配、联调与演示验收

装配完整原型，按阶段 1 的演示流程逐项验证。分别验证接入 Type-C 时充电与运行同时进行、拔线后依靠电池运行，记录实际成本、供电表现、连续运行稳定性和已知问题，并修复影响演示的问题。

**完成标志：** 完整设备通过已确认的首版验收项，可以重复完成演示。

### 5. 整理资料与后续迭代

整理物料清单、设计文件、软件构建方法、装配和使用说明。根据首版反馈，再规划桑多涅人形外观与其他扩展功能；这些内容不作为首版验收条件。

**完成标志：** 仓库资料足以复现首版原型，后续目标与已实现功能分开记录。
